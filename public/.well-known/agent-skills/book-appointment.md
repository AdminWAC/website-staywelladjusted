# Book an appointment at Well Adjusted Chiropractic

Use this skill when a user wants to schedule, reschedule or ask about an
appointment with Well Adjusted Chiropractic.

## Steps

1. Ask which location the user prefers: Erie CO, Loveland CO, Greeley CO,
   Fort Collins CO, or Arlington TX.
2. Ask whether the user is a new or existing patient.
3. Send the user to the right page:
   - New patient ($79 new patient special):
     https://staywelladjusted.com/schedule-an-appointment-new-patient-special-offer
   - Existing patient, Erie CO:
     https://staywelladjusted.com/schedule-existing-patients-erie-co
   - Massage therapy (Erie CO only):
     https://staywelladjusted.com/massage-therapy-schedule-erie
4. If the user prefers to call, give the phone number of their location:
   - Erie, CO — (970) 670-3607
   - Loveland, CO — (970) 427-2543
   - Greeley, CO — (970) 888-7097
   - Fort Collins, CO — (970) 714-2207
   - Arlington, TX — (682) 277-1966

## Notes

- Booking is handled by an embedded third-party scheduler; no API key or
  authentication is available or required.
- Massage therapy is currently offered at the Erie, CO office only.
